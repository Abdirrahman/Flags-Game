# Draw Flags From a Shuffled Pool

During a Time Challenge, correct answers are drawn from a shuffled Flag Pool rather than selected by pure random choice every Round. This avoids frustrating immediate repeats while still supporting unlimited Rounds by refilling and reshuffling the pool after all Playable Flags have appeared.

## Consequences

- A Flag should not appear as the correct answer again until the current Flag Pool is exhausted.
- After exhaustion, the Flag Pool is refilled from the Playable Flags and shuffled again.
- Each Round has exactly four Answer Choices: one correct Country Name and three Distractors.
- Distractors are selected randomly from the loaded Flag Dataset, excluding only the current correct Country Name.
- Distractor use does not affect the Flag Pool and does not prevent a country from appearing as a correct answer in a nearby Round.
- The four Answer Choices are shuffled independently for every Round.
